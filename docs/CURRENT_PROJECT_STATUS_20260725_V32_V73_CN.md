## 4. 当前运动规划和速度

### 4.1 G-code

- 支持：`G0`、`G1`、`G4`、`G21`、`G90`、`G91`、`G94`、`M3`、`M5`、`M501`、`STATUS`、`STOP`
- 串口最大单行：192 字节
- 固件默认 F：600 mm/min
- 当前文字文件主动指定：F300 mm/min
- 落笔/抬笔同步等待：700 ms
- 落笔轨迹纸面分段：最大 1 mm
- 抬笔快速移动分段：最大 20 mm
- 运动队列容量：32 段

上位机必须逐行发送，每收到一行 `ok` 后再发下一行。发生任意 `error:` 后停止发送、复位、等待自动回零，再从文件第一行重新开始。

### 4.2 步进频率

- 画线：40..120 Hz
- 快速移动：80..200 Hz
- 手动点动：200 Hz
- 回零快速寻找：300 Hz
- 回零精确复找：100 Hz

### 4.3 V32 关节空间拐角规划

- 队列起步频率：40 Hz
- 每 2 个主步进脉冲增加 8 Hz
- 关节反向拐角按 40 Hz 精确停式处理
- 非反向拐角按夹角降低允许通过速度
- 队列执行反向减速可行性和正向加速可行性扫描
- 方向/回差补偿仍关闭
- 尚未加入 AMASS 式低速脉冲平滑

## 8. 恢复和继续工作的最短步骤

1. 解压唯一备份到没有中文路径问题的本地目录。
2. 打开 `keil\gpio_toggle_output_LP_MSPM0G3507_nortos_keil.uvprojx`。
3. 确认源码 Build ID 为 `PAPER_A4_STANDARD_GCODE_JUNCTION_PLANNER_V32`。

5. 上电后等待抬笔和自动回零完成。
6. 用 `STATUS` 确认 V32、空闲、限位释放和抬笔状态。
7. 使用 `tools\send_standard_gcode_wait_ok.ps1` 逐行发送标准 G-code。
8. 若继续定位小字问题，优先完成 V71 预走距离测试；不要先恢复固定方向预加载。
