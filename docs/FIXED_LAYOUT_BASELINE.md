# 固定摆放基线

从 `FIXED_LAYOUT_AUTHOR_AXIS_PROBE_V2` 开始，照片中当前纸张、底板和写字机的
相对摆放方式是唯一有效的物理基准。旧诊断文档中的纸面原点、纸面平移、
文字路径和方框位置均不自动继承。

## 当前最终纸面坐标定义

2026-07-23 用户明确指定：

- 纸面 `+X`：朝纸张右边；
- 纸面 `-X`：朝纸张左边；
- 纸面 `+Y`：朝纸张上边；
- 纸面 `-Y`：朝纸张下边。

这是后续正方形和竖排书写唯一有效的目标坐标定义。下列作者命令轴方向仅是
机械原始命令方向的历史记录，不再等同于最终纸面坐标。

当前阶段只保留机械本体所必需的参数：连杆长度、限位方向、归零角度和
每度脉冲。作者已经实机确认的原始命令轴方向为：

- `+X`：当前俯视照片向上；
- `-X`：当前俯视照片向下；
- `+Y`：当前俯视照片向左；
- `-Y`：当前俯视照片向右。

M801 使用作者的命令坐标 ALIGN=`(150,20) mm`。纸面原点和平移仍保持
`UNSET`，必须用全程抬笔的门控试动重新确认。

确认顺序：

1. 上电自动归零，确认笔已抬起且两个限位均释放。
2. 执行 `gcode/FIXED_LAYOUT_AUTHOR_AXIS_01_ALIGN_V2.gcode` 到作者 ALIGN。
3. 依次执行 X `+10/-10` 和 Y `+10/-10`，每次都回到中心。
4. 记录照片视角下 `+X`、`-X`、`+Y`、`-Y` 的实际方向。
5. 根据实测方向定义纸面原点和有效矩形，之后才生成正方形路径。

在第 4 步完成前，固件不包含落笔动作，也不接受普通 G-code。

## V3 原点与坐标轴测量标记

`FIXED_LAYOUT_ORIGIN_AXES_DRAW_V3` 把纸面理论原点 `P0` 固定为当前俯视
照片中的纸张右下角。为避免贴边绘制和已知的 `command X < 150 mm`
危险区域，实际画出的测量基准点 `O` 使用命令坐标 `(170,20) mm`。

- 从 O 出发、固件标为 `+X` 的箭头长度 30 mm；
- 从 O 出发、固件标为 `+Y` 的箭头长度 30 mm；
- O 到照片下方纸边的垂直距离记为 `A`；
- O 到照片右方纸边的垂直距离记为 `B`。

V3 只使用旧作者平移估计确保首次标记大致落在纸内，不把旧平移作为最终值。

### 2026-07-23 实测结果

```text
A = O 到照片下方纸边 = 218 mm
B = O 到照片右方纸边 = 142 mm

paper O   = (218,142) mm
command O = (170,20) mm
```

上述数据只确定了一个共同锚点。现场照片确认固件 `+X/+Y` 与纸边之间存在
旋转，所以此前的纯平移试算
`command_x = paper_x - 48`、`command_y = paper_y - 122` 已作废，不能用于
正方形或文字路径。

保持本次 V3 标记和固定摆放不动，继续测量 `+X` 箭头尖端、`+Y` 箭头尖端
分别到同一纸张下边和右边的垂直距离。用三个点建立完整二维变换：

```text
P0 = (218,142)                       # O 点纸面坐标
PX = (AX,BX)                         # +X 箭头尖端纸面坐标
PY = (AY,BY)                         # +Y 箭头尖端纸面坐标

P(C) = P0
     + (command_x - 170) * (PX-P0)/30
     + (command_y - 20)  * (PY-P0)/30
```

得到并验证这四个尖端距离前，不生成正方形路径。

### V3 三点实测与 V4 仿射校正

用户回报的第四项重复写成 `AX`，结合顺序与几何关系，V4 暂按
`BX=121 mm` 解释：

```text
P0 = (218,142)
PX = (189,121)
PY = (229,130)

旧 command +X 30 mm -> paper (-29,-21) mm，长度 35.805 mm
旧 command +Y 30 mm -> paper (+11,-12) mm，长度 16.279 mm
两向量夹角约 96.6 deg
```

所以现场误差同时包含方向、旋转和两轴比例，不能只做旋转。局部
paper-to-command 逆变换为：

```text
command_x = 170
          - 0.621761658 * (paper_x - 218)
          - 0.569948187 * (paper_y - 142)

command_y = 20
          + 1.088082902 * (paper_x - 218)
          - 1.502590674 * (paper_y - 142)
```

V4 先从同一个 O 绘制校正后的两条 20 mm 纸面轴：

```text
paper O            (218,142) -> command (170.000, 20.000)
paper +X tip       (238,142) -> command (157.565, 41.762)
paper +Y tip       (218,162) -> command (158.601,-10.052)
```

V4 验证通过之前仍不生成正方形。

### V4 现场判废

V4 现场照片确认新绘制的两条轴不再垂直。原因是把不一致的四个边距测量
强制解释为任意仿射变换，产生了不应存在的剪切。V4 固件和换算矩阵禁止
继续使用。

照片还显示 V3 与 V4 的实际起点没有明显重合，但两版均使用相同的 command
O `(170,20)`。在固定摆放未改变的前提下，必须先排除自动归零重复性问题。

### V5 归零重复性单点测试

V5 不使用任何纸面坐标换算，也不画轴。每次复位、自动归零后：

```text
M801：抬笔移动到 command R=(180,20)
M802：XY 不移动，只落一个点并立即抬笔
```

在机器和纸张完全不动的条件下重复三轮。三点中心偏差不超过 `0.5 mm`
才继续做保持直角的旋转校正；偏差超过 `1.0 mm` 则先检查限位触发、
消抖、回退释放和归零方向。

### V5 现场结果与 V6 正交旋转

用户确认 V5 三次单点结果正确，归零重复性通过。V6 以 V5 测试点
`command O=(180,20)` 为起点，只应用刚性正交旋转：

```text
旧 command +X：相对纸张向下方向向右偏约 20.5 deg
目标 paper +X：朝纸张上边
目标 paper +Y：朝纸张左边

paper +X 20 mm -> command (161.267,27.004)
paper +Y 20 mm -> command (172.996, 1.267)
```

两条 command 向量长度均为约 `20 mm`，夹角严格为 `90 deg`，不包含
剪切和独立轴缩放。V6 现场确认方向、直角和长度之前仍不画正方形。

### V6 现场结果与目标坐标修订

用户确认 V6 向左的轴与纸边方向一致，但向上的轴整体向左上方倾斜，说明
该位置的实机二维映射并不严格保持命令空间正交。V6 的旧目标定义
`paper +X=上、paper +Y=左` 同时被用户正式改为：

```text
paper +X = 右
paper +Y = 上
```

新的 `+X` 可以直接使用 V6 向左轴的反方向。新的 `+Y` 需要根据 V6
向上箭头的实际左偏量单独求解，不能只交换两个命令向量。

### V7 X 向右、Y 向上校正

用户实测 V6 向上线总长 `20 mm`、尖端向左偏 `2 mm`：

```text
向上分量 = sqrt(20^2 - 2^2) = 19.8997 mm
左偏角   = asin(2/20) = 5.7392 deg
```

结合已确认的 V6 水平向左 20 mm 轴，V7 得到：

```text
paper +X right 20 mm -> command tip (187.004,38.733)
paper +Y up    20 mm -> command tip (161.876,28.922)
command O                    (180.000,20.000)
```

因为 V7 要抵消实机映射误差，两个 command 向量本身的夹角约为
`84.29 deg`；使用 V6 现场测量反算后的纸面预测向量为
`paper +X=(19.9995,0.0000)`、`paper +Y=(-0.0002,20.0000)` mm。

### V7 现场比例与 V8 单轴修正

V7 现场确认方向和垂直度正确，paper `+Y=20 mm`，但 paper
`+X=15 mm`。V8 只把 X command 向量乘以：

```text
20 / 15 = 4/3 = 1.333333
```

Y command 主轴向量保持不变。V8 目标为：

```text
paper +X right 20 mm -> command tip (189.339,44.978)
paper +Y up    20 mm -> command tip (161.876,28.922)
command O                    (180.000,20.000)
```

按 V7 现场模型反算，预测纸面向量为
`paper +X=(20.0001,-0.0001)`、`paper +Y=(-0.0002,20.0000)` mm。

### V8 现场整体旋转与 V9 纸边对齐

V8 现场确认两轴均为 20 mm、方向和垂直度正确，但 X/Y 整体共同逆时针
旋转。20 mm X 箭头尖端相对 O 向上偏约 `2.5..3.0 mm`，Y 轴呈相同
整体偏转。V9 取区间中值：

```text
rise  = 2.75 mm
angle = asin(2.75/20) = 7.9032 deg
```

V9 把完整校准坐标系统一顺时针旋转 `7.9032 deg`，不改变两轴的现场
比例关系。目标为：

```text
paper +X right 20 mm -> command tip (191.742,43.514)
paper +Y up    20 mm -> command tip (163.332,32.272)
command O                    (180.000,20.000)
```

现场模型反算得到
`paper +X=(20.0000,0.0002)`、`paper +Y=(-0.0001,20.0003)` mm。

### V9 通过与 V10 首个正方形

用户确认 V9 纸边对齐正确。V10 从 V9 O 点向纸张右方平移 30 mm，在空白
区域绘制首个 `20 x 20 mm` 闭合正方形，顺序为：

```text
右 20 -> 上 20 -> 左 20 -> 下 20 -> 回到起点
```

command 顶点：

```text
S  = (197.613,55.271)
X  = (209.355,78.785)
XY = (192.688,91.057)
Y  = (180.946,67.543)
S  = (197.613,55.271)
```

离线纸面反算四条边均约 20 mm，command 闭合误差为 0。现场需测量宽、
高、两条对角线和最终闭合间隙。

### V10 现场 X 上偏与 V11 单轴修正

V10 现场确认四边长度正确、Y 方向正确，但 20 mm X 边终点向上偏约
`2 mm`。因此这次不再旋转整个坐标系，只修正 X：

```text
X 水平分量 = sqrt(20^2 - 2^2) = 19.8997 mm
X 上偏角   = asin(2/20) = 5.7392 deg
```

V11 消除 X 的 2 mm 向上分量并把水平分量补足到 20 mm，Y command
向量完全不动。新方框放在 V10 方框上方 10 mm，command 顶点为：

```text
S  = (175.213, 72.006)
X  = (188.690, 94.405)
XY = (172.022,106.677)
Y  = (158.546, 84.278)
S  = (175.213, 72.006)
```

离线反算四条纸面边均约 20 mm，command 闭合误差为 0。
