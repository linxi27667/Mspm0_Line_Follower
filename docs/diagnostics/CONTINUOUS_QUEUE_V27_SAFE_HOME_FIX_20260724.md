# 连续运动 V27 安全回零修复

日期：2026-07-24

## 结论

本次“回零触碰限位时力度异常”不是限位中断优先级过低。

PA26、PA27 两个限位输入当前没有配置 GPIO 中断，而是由
`App_Stepper_Task()` 轮询。V26 新增连续运动队列后，
`App_Stepper_Dual_Stop()` 被改成了无条件停止共享定时器并清除
两轴运行状态。回零状态机每次只发一个脉冲，因此第二轴启动时会
误停第一轴，破坏原有的独立双轴回零节奏。

此外，旧的 STEP 引脚复用函数会同时操作 X、Y 两个 STEP 引脚，
也不适合两轴独立回零。

## V27 修复

- 连续队列没有活动、没有待执行块时，`App_Stepper_Dual_Stop()`
  不再操作传统独立 PWM 回零。
- X、Y 使用各自独立的 STEP 引脚复用函数，启动一轴不再改动另一轴。
- 首次快速寻边从 1000 Hz 降为 300 Hz。
- 第二次精确寻边保持 100 Hz。
- 默认回零入口同样降为 300 Hz，避免以后绕过上层参数时恢复到
  1000 Hz。

## 现场验证顺序

1. 抬笔并断开 G-code 发送。
2. 烧录 V27。
3. 手放在断电位置，只执行一次上电自动回零。
4. 观察两轴是否都在移动，触发各自限位后是否立即停止并回退。
5. 若任一轴持续顶住限位，立即断电，不执行圆测试。
6. 只有回零力度和退出动作正常后，才继续 V37 六圆测试。

当前轮询式停止每次只调度一个回零脉冲，但硬件 GPIO 限位中断仍可
作为后续的第二层失效保护；它不是本次异常的首要原因。
