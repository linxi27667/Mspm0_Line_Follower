| 序号 | 要求内容 | 性能指标 |

```c
void App_Grayscale_Init(void);              // 初始化GPIO
```

**算法核心：**
- 5路传感器布局：L2 | L1 | M | R1 | R2
- 偏差计算：加权求和
  ```
  偏差 = (-2)*L2 + (-1)*L1 + 0*M + (+1)*R1 + (+2)*R2
  ```
- 或更精细的8路传感器，偏差范围 -3.5 ~ +3.5

#### 4.2.2 OpenMV端程序开发

**核心功能模块：**

```python
# OpenMV主程序框架

import sensor, image, time, pyb

# 1. 初始化摄像头
sensor.reset()
sensor.set_pixformat(sensor.RGB565)
sensor.set_framesize(sensor.QQVGA)  # 160x120，高帧率
sensor.skip_frames(time=2000)

# 2. 颜色阈值定义
RECT_THRESHOLD = (0, 100, -128, 127, -128, 127)  # 黑色矩形阈值
LASER_THRESHOLD = (0, 50, 0, 50, 0, 50)  # 紫色激光点阈值（需实测调整）

# 3. 主循环
while True:
    img = sensor.snapshot()

    # 3.1 识别矩形靶
    for r in img.find_rects(threshold=RECT_THRESHOLD):
        # 计算靶心（矩形中心）
        center_x = r.x() + r.w() // 2
        center_y = r.y() + r.h() // 2

        # 3.2 检测激光点位置
        laser_blobs = img.find_blobs([LASER_THRESHOLD])
        if laser_blobs:
            laser_x = laser_blobs[0].x()
            laser_y = laser_blobs[0].y()

            # 3.3 计算偏差
            pan_error = center_x - laser_x   # 水平偏差
            tilt_error = center_y - laser_y  # 垂直偏差

            # 3.4 PID控制云台
            pan_output = pid_pan(pan_error)
            tilt_output = pid_tilt(tilt_error)

            # 3.5 驱动步进电机
            stepper_control(pan_output, tilt_output)

            # 3.6 命中判断
            if abs(pan_error) < 3 and abs(tilt_error) < 3:
                laser_on()  # 点亮激光指示
            else:
                laser_off()
```

### 阶段3：寻迹+瞄准联动（发挥要求1）

**目标：** 小车寻迹行驶同时瞄准靶心，D1 ≤ 2cm

#### 4.3.1 核心挑战

| 挑战 | 解决方案 |
|------|----------|
| **车身运动干扰** | OpenMV高帧率(QQVGA 60fps+)，PID快速响应 |
| **云台抖动** | PID微分项抑制振荡，陀螺仪辅助补偿 |
| **通信延迟** | 简化协议，减少数据量，提高UART波特率 |
| **时间同步** | MSPM0循迹主循环 + OpenMV并行运行 |

#### 4.3.2 系统集成方案

**方案A：OpenMV独立控制云台**

```
MSPM0: 循迹控制（主循环）
  ↓
OpenMV: 图像识别 + 云台PID + 步进驱动（并行运行）
  ↓
激光命中 → UART通知MSPM0
```

优点：OpenMV直接控制，响应快
缺点：OpenMV负载重

**方案B：MSPM0控制云台**

```
OpenMV: 图像识别 → 偏差计算 → UART发送
  ↓
MSPM0: 接收偏差 → 云台PID → 步进驱动
```

优点：MSPM0负载均衡
缺点：通信延迟

**推荐方案A**，OpenMV独立控制云台，减少通信延迟。

#### 4.3.3 调参要点

| 参数 | 调整方向 | 影响 |
|------|----------|------|
| **OpenMV帧率** | 提高帧率（降低分辨率） | 响应速度↑ |
| **云台PID Kd** | 适当增大 | 抑制振荡 |
| **循迹速度** | 弯道减速 | 稳定性↑ |
| **陀螺仪补偿** | 可选启用 | 姿态补偿 |

### 阶段4：光斑轨迹运动（发挥要求2）

**目标：** 激光光斑沿指定轨迹（如圆形）在靶面上运动

#### 4.4.1 实现方案

```python
# OpenMV轨迹生成

# 1. 标定：像素偏差 → 步进脉冲映射
# 实测：激光点移动1像素需要多少步进脉冲

# 2. 轨迹生成
def generate_circle_trajectory(center_x, center_y, radius, steps):
    trajectory = []
    for i in range(steps):
        angle = 2 * pi * i / steps
        x = center_x + radius * cos(angle)
        y = center_y + radius * sin(angle)
        trajectory.append((x, y))
    return trajectory

# 3. 执行轨迹
for (x, y) in trajectory:
    # 计算偏差
    pan_error = x - current_laser_x
    tilt_error = y - current_laser_y

    # 驱动云台
    stepper_move(pan_error, tilt_error)

    # 延时控制轨迹速度
    time.sleep_ms(50)
```

## 五、关键技术难点与解决方案

### 5.1 灰度循迹稳定性

| 问题 | 解决方案 |
|------|----------|
| **弯道脱轨** | 弯道减速，PID参数动态调整 |
| **直线振荡** | 适当减小Kp，增大Kd |
| **稳态偏差** | 引入积分项Ki（积分分离） |
| **传感器不一致** | 标定各传感器阈值，统一校准 |

**优化建议：**
- 8路传感器优于5路，偏差更精细
- 编码器速度闭环 + 循迹位置闭环 双闭环控制
- 弯道检测：传感器全黑 → 减速 + 大转向

### 5.2 激光命中精度

| 问题 | 解决方案 |
|------|----------|
| **像素-角度映射不准** | 实测标定：激光点移动1像素对应多少步进脉冲 |
| **云台抖动** | PID微分项抑制，机械结构加固 |
| **激光点检测不稳定** | 颜色阈值精细调整，环境光屏蔽 |
| **命中判断阈值** | 像素偏差 < 3~5 视为命中 |

**优化建议：**
- 先粗调后精调：大偏差快速移动，小偏差精细调整
- 激光点闭环反馈：检测激光点位置，闭环修正
- 标定距离：不同距离下的像素-角度映射不同

### 5.3 运动中瞄准

| 问题 | 解决方案 |
|------|----------|
| **车身晃动** | OpenMV高帧率，PID快速响应 |
| **云台滞后** | 增大PID Kp，减小积分项 |
| **通信延迟** | OpenMV独立控制云台，减少UART通信 |
| **视野抖动** | 摄像头固定牢固，减震设计 |

**优化建议：**
- OpenMV分辨率 QQVGA (160×120)，帧率可达 60fps+
- 云台PID Kd 适当增大，抑制振荡
- 可选：陀螺仪检测车身姿态，辅助补偿

### 5.4 圈数精确计数

| 问题 | 解决方案 |
|------|----------|
| **编码器计数不准** | 标定一圈脉冲数，考虑轮子打滑 |
| **起点检测不准** | 起点设置特殊标记（宽黑线或磁铁） |
| **弯道计数偏差** | 编码器里程 + 灰度起点检测双重验证 |

**推荐方案：**
- 编码器里程计为主
- 灰度传感器起点检测为辅（双重验证）

### 5.5 小车尺寸限制

| 约束 | 设计要点 |

| **长 ≤ 25cm** | 紧凑布局，电池选型注意体积 |

| **云台折叠** | 3D打印云台支架，折叠设计 |

### 5.6 独立电源开关

### A.2 PID控制器框架

```c
/**
 * @file    app_pid.c
 * @brief   通用PID控制器
 */

#include "app_pid.h"

void PID_Init(pid_controller_t *pid, float kp, float ki, float kd,
              float integral_limit, float output_limit) {
    pid->kp = kp;
    pid->ki = ki;
    pid->kd = kd;
    pid->integral_limit = integral_limit;
    pid->output_limit = output_limit;
    pid->integral = 0;
    pid->last_error = 0;
}

float PID_Calculate(pid_controller_t *pid, float target, float feedback) {
    float error = target - feedback;

    // 积分
    pid->integral += error;
    if (pid->integral > pid->integral_limit) pid->integral = pid->integral_limit;
    if (pid->integral < -pid->integral_limit) pid->integral = -pid->integral_limit;

    // 微分
    float derivative = error - pid->last_error;

    // 输出
    pid->output = pid->kp * error + pid->ki * pid->integral + pid->kd * derivative;

    // 输出限幅
    if (pid->output > pid->output_limit) pid->output = pid->output_limit;
    if (pid->output < -pid->output_limit) pid->output = -pid->output_limit;

    pid->last_error = error;

    return pid->output;
}
```
