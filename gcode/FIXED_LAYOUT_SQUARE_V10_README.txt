固定摆放 20 x 20 mm 正方形测试 V10

使用已经现场通过的 V9 纸面坐标：
  +X = 平行纸张下边，朝右
  +Y = 垂直纸张下边，朝上

方框位置：
  从 V9 测量 O 向纸张右方移动 30 mm，作为方框左下角 S。
  这样避免覆盖此前坐标轴标记。

绘制顺序：
  S -> 右 20 mm -> 上 20 mm -> 左 20 mm -> 下 20 mm -> S

command 顶点：
  S  = (197.613,55.271)
  X  = (209.355,78.785)
  XY = (192.688,91.057)
  Y  = (180.946,67.543)
  S  = (197.613,55.271)

离线纸面反算：
  side 1 = ( 20.0000,  0.0002) mm
  side 2 = (  0.0003, 19.9995) mm
  side 3 = (-20.0000, -0.0002) mm
  side 4 = ( -0.0003,-19.9995) mm
  command 闭合误差 = 0.0000 mm

安全检查：
  command X 范围 180.946..209.355 mm
  command Y 范围 55.271..91.057 mm
  最小关节裕量 27.455 deg

严格顺序：
1. 烧录并复位，等待自动归零完成。
2. STATUS 必须显示：
   id=FIXED_LAYOUT_SQUARE_20MM_V10
   state=WAIT_ALIGN action=M801 lim1=0 lim2=0 pen=UP
3. 发送 FIXED_LAYOUT_SQUARE_01_MOVE_V10.gcode。
4. 收到 state=WAIT_DRAW action=M802 后，确认笔尖位于空白纸面。
5. 发送 FIXED_LAYOUT_SQUARE_02_DRAW_V10.gcode。
6. 完成后测量：
   水平边长度；
   竖直边长度；
   两条对角线；
   最后闭合点与起点的间隙。

理想值：
  宽 = 20 mm
  高 = 20 mm
  两条对角线 = 28.284 mm
  闭合间隙 = 0 mm

任何方向错误、落点不在纸内、机械异常或限位触发，立即发送 STOP。
