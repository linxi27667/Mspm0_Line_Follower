# V34 字形 / 程序隔离测试

## 为什么需要这次测试

现有照片能看出异常与字体预览存在相关性，但仅凭照片不能排除：

1. G-code 生成或坐标变换问题；
2. 固件纸面映射问题；
3. 关节换向、笔架柔性或落笔瞬态；
4. 字库原始路径问题。

V34 在同一纸面高度、同一固件、同一映射、同一 `F180` 和同一 6 mm
切线预接近条件下，并排画三栏，从而只改变“路径来源”这一个变量。

该范围位于现有 V31、V33 文字下方，不会重合。

## 判读方法

### 1. A 栏也出现预览中没有的竖尾、弯头或断线

说明不能归咎于字库。下一步应检查落笔机构、方向回差、G-code 执行和纸面
映射，并对 A 栏的实际端点做照片测量。

### 2. A 栏干净，B、C 分别复现各自预览中的怪线

说明公共运动链路可以正确画简单几何，异常主要来自字库路径。

### 3. A、B、C 在相同运动方向出现相似偏差

说明存在方向相关的机械或落笔问题，例如某方向统一翘头、低头或起步侧移。

### 4. 只有左、中、右某一栏整体变形

说明问题与纸面位置有关，应检查局部纸面映射，而不是修改单个汉字。

## 拍照要求

- 能看到 A4 四角；
- 不放尺子、不遮挡三栏；

收到照片后，将分别比较 A、B、C 的落笔黑线与 V34 预览，而不是凭字是否
“好看”作判断。
