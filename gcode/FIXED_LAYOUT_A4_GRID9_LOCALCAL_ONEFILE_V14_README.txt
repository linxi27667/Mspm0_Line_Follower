固定纸张 A4 九区域独立形变校正单文件测试 V14

校正来源：
  使用 V13 九区域实画照片，将纸张透视还原为 210 x 297 mm。
  每个区域分别测量四个顶点，不再共用全局 X/Y 变换。
  每区独立修正横纵比例、旋转、剪切和相对边不平行误差。
  三列矩形的纸面 X 起点统一校正为 25、95、165 mm，
  分别在三个 70 mm 宽的区域内居中。

使用方法：
  1. 烧录 FIXED_LAYOUT_A4_GRID9_LOCALCAL_ONEFILE_V14.hex。
  2. 复位并等待自动归零。
  3. 发送 STATUS，确认版本：
       FIXED_LAYOUT_A4_GRID9_LOCALCAL_ONEFILE_V14
  4. 确认纸张仍为相同固定摆放，发送一次：
       FIXED_LAYOUT_A4_GRID9_LOCALCAL_ONEFILE_V14.gcode
  5. 固件自动画完九个校正后的 20 x 20 mm 矩形。

本版是第一次九区局部反算验证，画完后需要重新拍摄一张：
  - 镜头尽量位于纸张正上方；
  - 四个纸角全部入镜；
  - 不移动纸张和写字机；
  - 最好避免区域间连线，以便第二轮提取边线。

STATUS 查询进度；任何异常立即发送 STOP。
