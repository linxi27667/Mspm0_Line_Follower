
### 步骤 2：在 SysConfig 中配置定时器
**操作**: 用户需要在 SysConfig 中完成以下配置

#### TIMER_G7 (PWM 输出)
- Mode: PWM
- Clock Source: BUSCLK
- Clock Divider: Divided by 1
- Clock Prescaler: 8
- Timer Period: 1000
- Pin: PA17 (Output)

#### TIMER_G8 (编码器捕获)
- Mode: Capture
- Clock Source: BUSCLK
- Clock Divider: Divided by 1
- Clock Prescaler: 0
- Pin: PB21 (Channel 0), PB22 (Channel 1)

### 修改 2: `main.c`
```c
#include "ti_msp_dl_config.h"
#include "main.h"
#include "my_easylog.h"
#include "app_encoder_motor.h"

#define DELAY (16000000)

/* 50ms 打印定时器 */
static uint32_t s_print_tick = 0;
static uint32_t s_last_print_tick = 0;
#define PRINT_INTERVAL_MS  50

int main(void)
{
    /* 初始化系统配置 */
    SYSCFG_DL_init();
    my_log_init();
    log_i("RTT_INIT", "RTT_VIEW_INIT_SUCCESSFUL");
    
    /* 初始化电机系统 */
    App_Motor_System_Init();
    
    /* 启动电机前进 */
    App_Motor_Forward(500);
    
    /* 获取初始 tick */
    s_last_print_tick = 0;  // 或使用 DL_Timer_getTick()
    
    while (1) 
    {
        /* 更新电机状态（读取编码器） */
        App_Motor_Update_Status();
        
        /* 非阻塞 50ms 打印 */
        s_print_tick++;  // 或使用实际 tick 计数器
        
        if ((s_print_tick - s_last_print_tick) >= PRINT_INTERVAL_MS) {
            s_last_print_tick = s_print_tick;
            
            /* 打印电机数据 */
            log_i("MOTOR", "Speed:%ld Pos:%ld PWM:%ld",
                  App_Motor_Left.encoder_speed,
                  App_Motor_Left.total_position,
                  App_Motor_Left.current_pwm);
        }
        
        /* 其他任务处理 */
    }
}
```

## ⚠️ 注意事项

1. **Tick 计数来源**: 需要确认使用哪个定时器作为 tick 源
   - 选项 A: 使用 SysTick
   - 选项 B: 使用 TIMER_G0 作为 1ms tick 定时器
   - 选项 C: 在 SysConfig 中添加 tick 定时器

2. **编码器读取**: `App_Motor_Update_Status()` 会清零编码器计数
   - `encoder_speed` = 两次读取间的脉冲数
   - `total_position` = 累计位置

3. **PWM 占空比范围**: 取决于 Timer Period 设置
   - 如果 Period=1000，则 500 = 50% 占空比
