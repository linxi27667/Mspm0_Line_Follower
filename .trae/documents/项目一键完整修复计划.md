## 修复步骤

### 阶段1：修复编译错误（致命）

#### 1.1 bsp_key.c 缺少 include
**文件**: `BSP/Src/bsp_key.c`
**问题**: 使用 `GPIO_ReadPin`、`KEY_PRESS`、`KEY_RELEASE` 但未包含 `bsp_common.h`
**修复**: 添加 `#include "bsp_common.h"`

#### 1.2 app_key.c 函数调用参数不匹配
**文件**: `APP/Src/app_key.c`
**问题**: 
- `BSP_Key_Init()` 传0参数，声明需要2参数
- `BSP_Key_Scan(app_keys)` 传1参数，声明需要2参数
**修复**:
```c
BSP_Key_Init(app_keys, BSP_KEY_NUM);
BSP_Key_Scan(app_keys, BSP_KEY_NUM);
```

#### 1.3 app_uart.c 函数调用参数不匹配
**文件**: `APP/Src/app_uart.c`
**问题**:
- `BSP_UART_Init()` 传0参数
- `BSP_UART_Get_Frame(frame_buf, &frame_len)` 缺uart参数
**修复**: 创建 `bsp_uart_t App_UART` 对象，所有调用传入

#### 1.4 app_stepper.c 调用不存在的函数
**文件**: `APP/Src/app_stepper.c`
**问题**:
- 调用 `BSP_Stepper_Run()` 但BSP已改为 `BSP_Stepper_Start()` + `BSP_Stepper_Task()`
- 结构体赋值 `.Delay_us = HW_Delay_us` 但字段已删除
**修复**:
```c
// 初始化
BSP_Stepper_Init_Device(&App_Stepper_X);

// 启动
BSP_Stepper_Start(&App_Stepper_X, dir, steps, delay_ticks);

// 任务（在main循环中调用）
BSP_Stepper_Task(&App_Stepper_X);
```

### 阶段2：修复BSP层架构违规

#### 2.1 bsp_common.h 移除硬件头文件
**文件**: `BSP/Inc/bsp_common.h`
**问题**: 包含 `ti/devices/msp/msp.h` 和 `ti/driverlib/driverlib.h`
**修复**: 将硬件相关宏（GPIO_SetBits等）移到APP层，bsp_common.h只保留纯C类型定义和延时函数声明

#### 2.2 bsp_common.c 移除硬件操作
**文件**: `BSP/Src/bsp_common.c`
**问题**: 直接调用 `DL_SYSTICK_*` 硬件API
**修复**: 将Systick初始化移到APP层，BSP层只保留 `systick_ms` 变量和获取函数

#### 2.3 bsp_all.h 移除APP头文件包含
**文件**: `BSP/Inc/bsp_all.h`
**问题**: 包含所有APP头文件（反向依赖）
**修复**: 删除APP层include，APP层由main.c自行包含

#### 2.4 bsp_mpu6050.c 阻塞延时
**文件**: `BSP/Src/bsp_mpu6050.c`
**问题**: `mpu->Delay_ms(50)` 阻塞50ms
**修复**: 保留函数指针调用（由APP层决定是否阻塞），但添加注释说明

#### 2.5 bsp_sw_i2c.c 微秒延时
**文件**: `BSP/Src/bsp_sw_i2c.c`
**问题**: `I2C_DELAY(bus)` 每次调用阻塞2us
**修复**: 软件I2C必须用微秒延时，保留但添加注释说明这是协议要求

---

### 阶段3：修复APP层HW_函数规范

#### 3.1 app_led.c 绑定Gpio_Write
**文件**: `APP/Src/app_led.c`
**修复**: 为每个LED对象绑定 `Gpio_Write` 函数指针

#### 3.2 app_uart.c 创建uart对象
**文件**: `APP/Src/app_uart.c`
**修复**: 创建 `bsp_uart_t App_UART` 对象，绑定硬件函数指针

#### 3.3 app_stepper.c 改用非阻塞API
**文件**: `APP/Src/app_stepper.c`
**修复**: 移除 `.Delay_us` 绑定，改用 `BSP_Stepper_Start` + `BSP_Stepper_Task`

#### 3.4 APP文件移除 main.h 包含
**文件**: 所有 `APP/Src/app_*.c`
**修复**: 用 `ti_msp_dl_config.h` 替代 `main.h`（如果main.h只包含硬件头文件）
